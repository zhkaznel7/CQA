# Фронтенд CQA

Из папки `frontend` запустите `npm ci` и `npm run dev`. В разработке Vite отправляет запросы `/api` на `http://127.0.0.1:3000`. Чтобы изменить адрес прокси, задайте `CQA_BACKEND_URL` перед запуском. Для статической сборки настройте прокси на сервере размещения или задайте `VITE_API_BASE_URL` перед `npm run build`. Тесты запускаются командой `npm test`.

## Данные экранов

| Экран | Запросы |
|---|---|
| Диалоги и транскрипт | `GET /api/conversations`, `GET /api/conversations/:id` |
| Чек-листы | `GET /api/checklists`, `GET /api/checklists/:id`, `POST /api/checklists` (создание), `PUT /api/checklists/:id` (следующая версия) |
| Наборы данных | Загрузка из API по `group_id` через `POST /api/conversations/import` или из исходного файла JSON через `POST /api/conversations/upload`. Здесь же можно выбрать версию чек-листа, оценить всю группу и скачать `results.json` через `GET /api/exports/:dataset`. Для групповой оценки оставьте страницу открытой. |
| История оценок | `GET /api/evaluations?conversationId=…` возвращает доступные версии. Последняя оценка автоматически открывается в карточке через `GET /api/evaluations/:id`. |
| Оценка | `POST /api/evaluations` с внутренними UUID диалога и версии. Ответ включает критерии, исходные реплики-доказательства и серверный итог. Признак `isMock` приходит от сервера. |
| Апелляции | `POST /api/appeals` с evaluationId, criterionId и комментарием. Список и карточка — `GET /api/appeals` и `GET /api/appeals/:id`. Решение с причиной — `PATCH /api/appeals/:id/decision`. В карточке обращения видны исходный и текущий итоги сервера. |

Разделы находятся в `src/features/`, маршруты — в `src/app/routes.js`, общий HTTP-клиент — в `src/shared/api.js`. При недоступном API экраны показывают ошибку. Учебные данные для автотестов находятся в тестовых файлах и `tests/fixtures/`.

Аудиоразбор открывается для диалога с `audioUrl`. Для страницы плеера организаторов WaveSurfer загружает MP3 через `GET /api/conversations/:id/audio`. В списке диалогов доступен фильтр «Голосовые звонки». Для привязки текста используются интервалы `startMs/endMs` относительно начала записи. Если есть интервалы отдельных слов, отображаются слова. При наличии только интервалов реплик отображаются реплики целиком. Метки времени без привязки к записи остаются в транскрипте. Если волну загрузить не удаётся, доступны браузерный плеер и исходная ссылка.
