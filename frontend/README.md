# Frontend

Участник 3 отвечает за навигацию, редактор чек-листа, список диалогов, карточку результата, переход к репликам и плеер. Вызовы серверного API собираются в `js/api.js`.

Участник 4 ведёт интерфейс подачи и рассмотрения апелляций в `js/appeals.js` и `css/appeals.css`. Участник 3 подключает этот экран через `mountAppeals(container, context)` и обновляет карточку после решения проверяющего.
