# Оценка диалогов

Из каталога `backend` запустите `node ai/server.mjs`. Сервер слушает `127.0.0.1:8001`. Основной API отправляет один POST на `/v1/evaluations` с транскриптом и полным снимком выбранной версии чек-листа. Ответ содержит идентификаторы диалога и версии, объяснения, цитаты и индексы реплик с нуля. Сумму рассчитывает основной API. `GET /health` возвращает статус и имя активной модели.

### Локальная оценка

`AI_PROVIDER=local` использует **CQA rules-v1**. Это воспроизводимый алгоритм для RU/KZ/EN. Он определяет тип обращения, порядок вопросов, ответов и проверки личности, ищет характерные формулировки нарушений и завершения разговора. Обработка локальная, стоимость внешних вызовов на диалог — 0.

Правила используют только текст. Они могут пропустить перефразированную просьбу, неявную грубость или раскрытие сведений. Корректность финансовой консультации относительно внешней базы знаний и интонация звонка этим режимом не проверяются.

Редактор может менять веса, ключи, разделы, числовые значения ступеней с прежними описаниями и добавлять проверки фразы. Для такой проверки выберите тип «Да/Нет» или флаг, отключите N/A и задайте, например, описание `Оператор использует фразу «Спасибо»`. Ищется фраза в репликах оператора без учёта регистра. Для новых содержательных критериев или произвольных формулировок включите Gemini.

### Gemini

Для запуска через Compose задайте в корневом `.env` значения `AI_PROVIDER=gemini`, `GEMINI_API_KEY` и `GEMINI_MODEL` и пересоздайте сервисы командой `docker compose up -d`. Идентификатор модели должен быть доступен вашему ключу. В этом режиме сервер передаёт транскрипт и версию рубрики Google и делает один запрос на оценку. После ответа проверяет шкалы, допустимость N/A, диапазоны и точное совпадение цитат с оригиналом.

При ответе с данными об использовании сервер выводит `model_usage` в `docker compose logs ai`. Для платного тарифа оценка стоимости одного диалога в долларах равна `(input_tokens × цена входа за 1 млн + output_tokens × цена выхода за 1 млн) / 1 000 000`. Выход включает токены рассуждения. Для локальной выгрузки эти расходы отсутствуют.

### Проверка

```powershell
node --test ai/evaluator.test.mjs
node ai/evaluation/compare.mjs "путь/к/DEV.json"
```

Второй команде можно передать вторым аргументом официальный файл результатов для сопоставления с черновой разметкой. Она проверяет хеши исходных транскриптов. На 12 синтетических чатах DEV локальные правила совпали с черновыми метками команды в 54 из 67 рассмотренных решений. Из 96 меток 29 ранее отмечены спорными и исключены. Эталон организаторов не предоставлен.
