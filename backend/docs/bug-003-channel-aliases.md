# BUG-003: N/A приветствия для channel="voice call"

Статус: **исправлен**, проверено 8 ноября 2026.

## Причина и исправление

В DEV-наборе подтверждены 60 записей `agent chat` и 5 записей `voice call`.
HTTP-адаптер распознавал `voice call`, `voice` и `call`, но `confirmApplicability()`
проверял исходную строку только по списку `voice/call`. Поэтому корректный ответ AI
с N/A отвергался с `502 AI_NA_UNCONFIRMED`, несмотря на независимое подтверждение.

Сопоставление известных каналов вынесено в `src/modules/conversations/channels.js`.
HTTP-запрос и проверка применимости используют общую функцию `canonicalChannel()`.
При проверке правила канонизируются обе стороны сравнения — канал разговора и
допустимые каналы сохранённого правила. Все три обозначения звонка имеют одну семантику.
Текстовые и неизвестные каналы не становятся звонками.

Канонизация выполняется только в памяти. Исходный `Conversation.channel` не обновляется;
GET возвращает прежнюю строку. Импорт и формат API не изменены. Официальная v2 по-прежнему
содержит `channels: ["voice", "call"]`; её схема, seed, формулировки, веса и Scoring Engine
не менялись. Независимое подтверждение для конкретного диалога, версии и критерия остаётся
обязательным. Общая проверка также используется CLI `confirm-na` и апелляциями.

## Проверки

Новый unit-тест сначала запущен до исправления: воспроизведён `502 AI_NA_UNCONFIRMED`
для `voice call`. После исправления:

- Полный `npm.cmd test`: **109 успешно, 0 ошибок, 0 пропущено** (ранее 107; добавлены
  unit-регрессия и интеграционная регрессия через командный HTTP mock).
- Новый HTTP-тест запускает именно `ai/mock-server.mjs` отдельным дочерним процессом
  на свободном localhost-порту. Gemini не запускается. Дочерний процесс завершается
  после проверки; существующие сервисы не останавливаются.
- Для каждого из `voice call`, `voice`, `call` без подтверждения — 502, записей оценки нет;
  с подтверждением `recording_start_missing` — 201, N/A для `01`, итог **38.89**.
- Старый чек-лист v1 остаётся доступным: N/A приветствия запрещён, обычный результат 35.
- Повторная оценка — 200/reused, исходные данные не переписываются; GET восстанавливает
  оценку и доказательства. PostgreSQL и GET сохраняют исходный channel для каждого алиаса.
- `agent chat` и `chat` с той же системной репликой и тестовым подтверждением не получают
  N/A, итог 35. Принудительный N/A от тестового адаптера для текстовых каналов отклоняется
  с 502; соответствующая апелляция — с 422.
- Обычный `voice call` без системного признака обрезки получает применимый критерий,
  итог 35. Неподтверждённый N/A не разрешён. Неверный тип подтверждения отклоняется.
- Регрессии апелляций проверяют все три обозначения звонка и запрет для текстовых каналов.

Использована новая локальная база `cqa_bug003_test_1794077535724` на `127.0.0.1:5432`.
Все семь миграций применены только к ней. Docker и существующий volume не использовались.
Основная база и прежняя `cqa_test` не изменялись; синтетические конкурентные фикстуры
сохранены только в новой тестовой БД. SHA-256 подтвердили неизменность 22 защищённых файлов:
реального `.env`, AI, официальных seed и Scoring Engine.

## Повторение в PowerShell

В отдельном окне PowerShell можно использовать сохранённый локальный URL новой тестовой
базы без вывода пароля. Файл находится в игнорируемой `.tmp/`:

```powershell
Set-Location C:\Users\zhanel\CQA\backend
$testEnvironment = Get-Content '.tmp/bug003-1794077533711/database.env' -Raw -Encoding UTF8
$env:DATABASE_URL = $testEnvironment.Trim().Substring('DATABASE_URL='.Length)
npm.cmd run db:status
npm.cmd test
```

Весь HTTP-сценарий входит в полный набор тестов. Отдельный запуск набора Evaluations:

```powershell
npm.cmd run test:evaluations
```

Только unit-регрессия, без PostgreSQL:

```powershell
node --test --test-name-pattern='BUG-003' tests/ai-client.test.js
```

Для HTTP-регрессии требуется соседняя папка `ai/` с командным mock. В Backend-only копии
без этого исходника HTTP-проверка будет явно помечена как пропущенная; в выполненном
прогоне она действительно запускалась. Лог полного прогона:
`.tmp/bug003-1794077533711/backend-tests.log`; контроль неизменности: `verification.json`
в той же папке. Git merge, commit и push не выполнялись.
