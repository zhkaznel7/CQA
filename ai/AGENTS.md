# Контекст проекта SQA — Freedom Broker CQA Hackathon

Мы участвуем в 24-часовом хакатоне Freedom Broker. Разрабатываем Conversation Quality Analytics — систему автоматической оценки качества работы операторов.

**Команда:** 4 человека. Моя личная зона ответственности — LLM / AI Engineer. Я должен самостоятельно реализовать интеллектуальный модуль оценки, не дожидаясь остальных участников.

**Репозиторий:** https://github.com/zhkaznel7/SQA

## Требования

- Анализ диалогов на RU, KZ и EN.
- DEV-набор: 65 диалогов (60 чатов и 5 звонков).
- Оценка по 8 критериям из официального чек-листа Freedom Broker.
- Ответы Да / Нет / N/A и предусмотренные шкальные значения.
- Объяснение и конкретное доказательство из транскрипта для каждого критерия.
- Проверка индексов реплик и достоверности цитат.
- Расчёт баллов отдельным кодом с учётом весов, N/A и округления до двух знаков.
- Грубые ошибки фиксируются отдельно.
- Промпт автоматически формируется из конфигурации чек-листа, поэтому добавление и изменение критериев не требует изменения кода.
- Модуль должен предоставлять функции для интеграции с Node.js + Express.

## Уточнения организаторов

1. Результаты сравниваются с эталоном по каждому критерию, поэтому точность отдельных ответов приоритетнее итогового балла.
2. Контрольные 10 транскриптов будут только чатами.
3. При изменении критерия необходимо повторно оценить контрольные диалоги.
4. Если начало записи звонка отсутствует, для приветствия организаторы разрешили N/A как исключение.
5. Способ проверки идентификации команда должна обоснованно разработать самостоятельно.
6. У организаторов есть база знаний для проверки консультаций, но формат доступа ещё не уточнён.
7. Подтверждено округление половины вверх: 50,625 → 50,63.

## Мои основные модули

- `server/evaluator.js` — формирование промптов, вызов LLM, структурированные результаты и проверка доказательств.
- `server/scoring.js` — детерминированный расчёт баллов.
- Автоматические тесты для всех критериев и особых случаев.
