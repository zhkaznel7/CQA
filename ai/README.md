# AI-сервис CQA

Запуск из корня проекта (Node.js 20+, без npm-зависимостей):

```sh
node ai/mock-server.mjs
```

Backend вызывает POST /v1/evaluations с JSON, локально AI_BASE_URL=http://localhost:8001.
Если Backend в Docker, а AI на Mac, используйте http://host.docker.internal:8001.
Порт переопределяется через PORT. Для запроса из файла:

```sh
curl -sS -H 'Content-Type: application/json' --data-binary @ai/mock-request.json http://localhost:8001/v1/evaluations
```

Mock возвращает синтетический ответ на каждый ключ переданной версии. Если разрешён N/A, он выбирает N/A; иначе для scale берёт первую переданную ступень, для boolean и flag — false. Цитата дословная, индекс начинается с нуля, границы checked_range включительны. Эти данные проверяют транспорт и scoring, для проверки точности нужен реальный evaluator. Backend отвечает за баллы и сохранение.

Для проверки ошибок провайдера запустите процесс с MOCK_ERROR_STATUS=502, 503 или 504. Ошибки JSON и структуры запроса проверяются и без этого режима (400 и 422). Повторов запросов в mock нет. Для smoke-теста новой версии поменяйте id, version, ключ критерия и его шкалу в копии запроса.

По умолчанию bind на 127.0.0.1. Для доступа из контейнера при необходимости задайте HOST=0.0.0.0.
