# AI и расчёт баллов

Участник 2 отвечает за исходный чек-лист, промпт, вызов модели, проверку доказательств и тесты расчёта баллов.

- `evaluateConversation()` принимает диалог и версию чек-листа, возвращает оценки по критериям, объяснения и ссылки на реплики.
- `computeScore()` рассчитывает итог по весам и шкалам с учётом N/A. Backend использует её как для исходной оценки, так и при пересмотре.
