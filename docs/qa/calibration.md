### Проверка источников перед сравнением меток

Проверить один сохранённый ответ по тому JSON-запросу, который был отправлен адаптеру. Запускать сравнение меток после успешной проверки источников.

```sh
python3 docs/qa/tools/check_evidence.py --input /path/to/request.json --response /path/to/response.json
```

Для DEV вместо --input указать --dev data/dev.json. Для архивного массива без conversation_id дополнительно указать --id, например p1-ru-025. Проверяются все цитаты в массиве evidence, точное вхождение в текст указанной реплики и включительные границы checked_range при его наличии. Ответ с одним диапазоном и пустым списком цитат допускается по контракту бэкенда. Код выхода 1 означает ошибку. Соответствие доказательства смыслу критерия проверяет разметчик.

Контроли для BUG-004: цитата из реплики 1 прошла при диапазоне [1, 1] и отклонена при [0, 0]. Также отклонены цитата с ошибочным индексом, выдуманная цитата и диапазон за границей транскрипта. В сохранённом пилоте p1-ru-025 проверены восемь цитат; все checked_range в этом ответе равны null.
