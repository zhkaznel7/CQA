Первая партия для сравнения с оценками модели. Разметку подготовил Codex по тексту DEV до получения ответов модели. Статус всех строк — кандидат в эталон, экспертная проверка ожидается. Источники зафиксированы в коммите 8412e7e: [DEV](https://github.com/zhkaznel7/CQA/blob/8412e7e/data/dev.json) и [чек-лист v1](https://github.com/zhkaznel7/CQA/blob/8412e7e/backend/prisma/seed/official-checklist.json). Индексы реплик начинаются с 0, обе границы диапазона включены. Ключи 01–08 соответствуют c1–c8. Для 08 «Нет» означает отсутствие выявленной грубой ошибки.

## Сравнение после подключения модели

Зафиксировать утверждённую версию разметки до просмотра прогнозов. Сопоставлять ответы по conversation_id и ключу критерия. Для каждого расхождения записать эталон, ответ модели, индекс подтверждающей реплики и объяснение. Предварительные строки до экспертного подтверждения учитывать отдельно. Четыре диалога подобраны для покрытия разных ситуаций и не дают оценки точности на всём DEV.
