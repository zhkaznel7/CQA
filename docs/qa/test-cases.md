## T13 · Последовательный пересчёт на бэкенде

Проверена функция calculateScore из backend 8412e7e на официальном чек-листе v1. Исходные ответы T12 с c3 = N/A, c4 = 15, c6 = 7 дали 88,13. После изменения только c4 на 20 получено 94,38. Во второй набор внесено только следующее изменение — c6 с 7 на 10. При c4 = 20 и c6 = 10 итог составил 100. Контроль с одним изменённым c6 и исходным c4 дал 93,75.

Ручная сверка: сумма применимых весов 80. Первый пересмотр добавляет 5 исходных баллов, второй при весе c6 = 15 добавляет 15 × (10 − 7) / 10 = 4,5. Итог (70,5 + 5 + 4,5) / 80 × 100 = 100. Для сквозного T13 остаётся проверить, что API собирает оба решения из базы, сохраняет исходную оценку и возвращает итог с обеими причинами в истории.
